# ИПБ бойынша тренинг-сайт (БЖЗҚ)

Қазақ тіліндегі викторина сайты: **Қызметкер** тест тапсырады, **Тренер** тестті бастап, нәтижелер мен дашбордты көреді.

## Кіру коды (Тренер)

**`IPB2026`** (регистр маңызды емес). Өзгерту: `config.js` → `CODE`.

## GitHub Pages-ке орналастыру

1. GitHub-та жаңа репозиторий ашыңыз.
2. Осы архивтің **ішіндегі файлдарды** (`index.html`, `app.js`, ...) репозиторийдің түбіріне жүктеңіз (папкасымен емес).
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
4. 1–2 минуттан соң сайт `https://<логин>.github.io/<репо>/` мекенжайында ашылады.

Серверді өзіңіз орнатудың қажеті жоқ.

## Қалай жұмыс істейді

1. Тренер сайтқа кіреді: **Тренер** → аты + код.
2. Қызметкерлер сілтемені ашады: **Қызметкер** → аты. Күту экраны шығады.
3. Тренер: **Басқару** → «1-тест» немесе «2-тест» → **Тестті бастау**. Барлық қызметкерде тест бірден ашылады.
4. Қызметкер жауап беріп, жібереді → балл және «Қатысқаныңыз үшін рақмет!» көрінеді.
5. Тренер **Тестті аяқтау** батырмасын бассын: жауап бермегендердің қолда бар жауаптары автоматты жіберіледі.
6. **Нәтижелер** — әр адамның қателерін талдау, CSV жүктеу. **Дашборд** — дұрыс жауап %, жиі қателесетін сұрақтар, үздік нәтижелер, жұмыс қажет (<60%), баллдар бөлінісі.
7. Келесі топқа дейін **Барлық нәтижелерді тазалау** басыңыз.

Тренер тақтасын тренинг барысында ашық ұстаңыз.

## Техникалық ескертпелер

- Нақты уақыттағы байланыс тегін ашық MQTT серверлері (HiveMQ, EMQX) арқылы жүреді; тіркелу не баптау керек емес. Мәліметтер жеке бөлме атауымен (`config.js` → `ROOM`) бөлінген.
- Тренер коды браузерде тексеріледі (қорғаныс деңгейі «тренинг үшін»). Құпия мәліметтерді мұнда сақтамаңыз.
- Қызметкерлердің аты-жөні мен жауаптары ашық серверде уақытша сақталады. Тренинг соңында «Тазалау» батырмасын басыңыз.
- Тренингтен бұрын 2 құрылғыда (тренер + қызметкер) тексеріп алыңыз.
- Сұрақтар: `easy.js` (жеңіл) және `hard.js` (жағдайлық). Формат: `{q, o:[3 жауап], a:дұрыс индекс}`.
